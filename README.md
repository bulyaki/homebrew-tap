# homebrew-tap

Homebrew tap for `hermes-icon` and macOS utilities.

## Installation

```bash
brew install bulyaki/tap/hermes-icon
```

Or tap first and then install:

```bash
brew tap bulyaki/tap
brew install hermes-icon
```

## Available Formulae

- **hermes-icon** — Customize the Hermes desktop app icon across every surface and automatically persist it across updates ([bulyaki/hermes-icon](https://github.com/bulyaki/hermes-icon)).
